# Código Divino — Experiência Editorial Web

Projeto web em espanhol voltado à apresentação de conteúdo bíblico de forma visual, organizada e acessível.

A página foi desenvolvida como uma experiência editorial digital, com foco em leitura, navegação por temas e apresentação clara de conteúdo extenso.

## Objetivo

Transformar conteúdo denso em uma experiência de leitura mais simples e visual, mantendo uma estrutura fácil de navegar.

## Destaques

- página responsiva;
- identidade visual própria;
- organização de conteúdo editorial;
- uso de imagens e seções temáticas;
- experiência voltada à leitura;
- publicação com domínio/configuração web.

## Tecnologias

- HTML
- CSS
- JavaScript
- GitHub Pages

## Meu papel

- desenvolvimento front-end;
- estrutura da página;
- organização visual;
- responsividade;
- composição do conteúdo;
- publicação.

## O que este projeto demonstra

- criação de páginas com grande volume de conteúdo;
- hierarquia visual;
- adaptação para outro idioma;
- experiência editorial;
- organização de navegação.
